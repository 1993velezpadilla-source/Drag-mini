# FOREVER FREQUENCY — City Zero (Native 3D Alpha)

A **native Godot 4.4** third-person Android game (upgraded La Caldera art pass): city exploration, companion evolution, music composition, farm harvesting, business investment, and a concert stage. No HTML wrapper. GDScript is plain text and easy to modify.

## Controls
- PC: WASD/arrow keys walk, right mouse drag rotates camera, E interacts.
- Android: left thumb virtual joystick, drag right side of screen to look, INTERACT button.
- Studio: repeat the eight-pad sequence, release a track, grow your audience.
- Home: bond with and evolve your companion.
- Garden: harvest on cooldown.
- Market: expand your businesses (offline coins, capped to eight hours).
- Radio: broadcast your latest track.
- Stage: unlock with 50 fans + 200 coins and play gigs.

## The Blender pipeline
`blender -b -t 2 --python tools/build_assets_blender.py` makes new editable original assets: `assets/city_zero_modular.blend`, `la_caldera_records.glb`, `moon_market.glb`, `forever_home.glb`, `pixel_garden.glb`, `nova_stage.glb`, `radio_one.glb`, `artist_avatar.glb`, `companion_nova.glb`, `city_car.glb` and optimized street props. Godot imports GLB at edit time. The game supports a fallback procedural studio if the GLB has not been built yet.

## Native Android build
The GitHub workflow `.github/workflows/forever-frequency-android.yml` installs Blender, builds 3D GLBs, runs engine/script tests, and exports **ARM64 APK** with the Godot Android export template. The output is a debug-signed playable test APK, **not a production release**. A Play Store/release signing keystore must be managed separately.

## Modding
Open in Godot. Edit `scripts/city_zero.gd`, `scripts/game_state.gd`, and `scripts/mobile_input.gd`; or change model geometry/materials with `tools/build_assets_blender.py`. `game_state.gd` stores a local save at `user://city_zero_save.json`. No ads, microtransactions, external accounts, or connection needed in this prototype.

## Constraints
Only a first vertical slice. Not yet multiplayer, full APEX DAW integration, full 3D model importer UI, Android live wallpaper, or a large streaming world. These require substantial subsequent development. Android low-end FPS is not yet device-benchmarked.

## Art direction / audit — La Caldera upgrade
- Main reference: *My Time at Sandrock* for third-person control and meaningful town progression; *Dragon Quest Builders 2* for building changes. Original artwork, not copied from those games.
- La Caldera Records' Blender facade is a unique warm red-brick, brass-and-glass downtown recording HQ with illuminated sign, acoustic-look entry and rooftop terrace.
- Other modules have independently editable Blender geometry and separate GLB imports, with fallbacks when the model kit is not generated.
- Rendering: sunset palette, less overexposure, batched procedural windows, GL Compatibility for older/mobile hardware.
- HUD fix: time label has an actual bounded width and does not wrap one character per line.
- Screen captures must be generated by Godot's framebuffer capture script; never substitute promotional art for real gameplay.
- Blender assets are not baked into source checkout until the Blender GitHub Actions job produces them. The Android APK remains a test build until on-device benchmarking.
