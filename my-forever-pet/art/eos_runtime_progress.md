# Full EoS roster integration, iteration 1
468 identified moves, 233 direct damage prototypes, 235 awaiting special rules or range confirmation. All original numerical fields and effect candidates retained in eos_move_audit.json. Added IDs eos_000..eos_558 are reserved in the save format; existing 54 slots unchanged. Prototype unlock levels are Kindria-original, not universal EoS learn levels (which differ by species). Damage still uses Kindria's model, not exact EoS. Accuracy uses current two-stage model. Single-hit basic damage is active, secondary effects, target-specific visual choreography, status and multi-hit moves remain incomplete. Shared original effect families are placeholders pending visual review, not final art. No proprietary assets imported.
