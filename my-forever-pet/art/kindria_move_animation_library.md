# Kindria reusable move-animation library
Original authored effects. Do not distribute Nintendo/Chunsoft ROM art or frame-by-frame replicas.
Research references: https://wiki.skytemple.org/Animation_Tables ; https://wiki.skytemple.org/List_of_Effect_Animations ; https://wiki.skytemple.org/Animation_ID ; https://projectpokemon.org/home/docs/mystery-dungeon-nds/wanwat-file-format-r50/ ; https://mysterydungeonwiki.com/wiki/Explorers_of_Sky:List_of_Moves .
Explorers separates caster motion, projectile and impact. Kindria uses stable move identifiers, tile path, an animation mode, colors, duration, 12 temporal frames, and independently pooled world-space particle trajectories. Current 66 enemy moves have exportable original animation sheets. Not all Explorers moves are implemented. Current sprites remain 2D with 3D terrain.
Future content pipeline: Blender authors original geometry, orthographic 48px transparent sprite renders, no antialiasing or copyrighted assets; Godot imports atlas via stable move ID. Character-independent effect data and learnsets should remain separate. Current Godot atlas source is versioned and deterministic; CI exports actual PNGs. No external ROM required.
