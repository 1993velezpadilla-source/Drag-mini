# Combat presentation research: Explorers and original Kindria
Sources inspected: https://wiki.skytemple.org/Animation_Tables ; https://wiki.skytemple.org/List_of_Effect_Animations ; https://wiki.skytemple.org/Animation_ID ; https://wiki.skytemple.org/List_of_Sound_Effects ; https://mysterydungeonwiki.com/wiki/Module:Explorers_of_Sky_Move_Data_Cell ; https://www.youtube.com/watch?v=zVRCYgMu0gM (public in-game move reference, not extracted assets).
Reference design: caster motion and origin offsets, move travel path, target effect, separate sounds. Vine Whip contact + impact; BubbleBeam head-origin projectile; Thunderbolt area vs ThunderPunch contact; Earthquake uses terrain/sound. Kindria patterns and timings are original, not a replica.
Tool candidates: https://extensions.blender.org/add-ons/sprite-sheet-maker/ ; https://godotengine.org/asset-library/asset/5543 ; https://gennai.itch.io/arcflux-lite ; https://friedspin.itch.io/combat-vfx-sfx-suite . Evaluate actual license and Godot 4.4 compatibility before importing; none imported in this change. Existing Blender original briar pilot passed run 45925768059.
Implementation: profiles for all move IDs; original 3D world lightning ribbon with white core/cyan edge, deterministic 24 Hz flicker and branches, distinct close/line/area layouts; positional 12-voice audio pool, three synthesized variants per move and phase, elemental oscillator/noise recipes, 22.05 kHz mono; separately timed launch/impact. This is a first pass; synthesized audio is not professionally mastered, actual Android GPU/audio profiling and comprehensive caster/target anatomy animation remain pending. No ROM sprites or sound extracted.
