# Reusable creature animation library
Only Mosky remains playable. LPC anatomy uses independently layered 64px sprites,
four directional rows for idle and walk; hurt is a one-row strip. The imported
parts remain authoring assets, not active pets. Adapt pivots per creature.
PixelFX uses pinned upstream MIT code to bake transparent spirit flame, fire breath,
heart pickup, bubbles and heal sprites in CI; no runtime third-party code.
Reward and affection use heart pickup; other effects are reserved for future
species. Retain the MIT license file. Godot Skeleton2D, Bone2D, AnimationPlayer and
SpriteFrames are compatible authoring paths for non-pixel rigs baked to atlases.
Mosky's native mood variants use the original silhouette, with lowered ears
and tail when weak/sad/sick; those are our own adaptation, not imported artwork.

## Iteration 67: native companion grounded gait and mood
The dungeon companion previously combined the 10fps walk sprites with an unrelated 3.5Hz body hop, and reset the animation clock whenever direction changed. Dungeon-only grounded gait now samples existing four native cells, reduces vertical lift, synchronizes squash to the foot phase, slows cadence under weakness/sickness and preserves phase on corners. Logical facing wins over residual interpolation; poison and reward choose existing sick/happy native mood variants, with low HP taking precedence over reward. The editable ten-column atlas and Pet Dash are unchanged; custom external atlases retain their authored cells. Added gait cadence, mood priority, and actual Sprite3D corner transition checks. Prior native hover CI was in progress at inspection; this commit pending CI and Android visual review.
