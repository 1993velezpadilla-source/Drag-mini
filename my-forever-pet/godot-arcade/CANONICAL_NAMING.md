# Kindra — Canonical naming

- **Kindra**: the world (not Kindria).
- **Mosky**: one creature; **Moskies**: plural.
- **Ponoko**: the original green forest mascot, previously displayed as Mosky.
- **Bunbi**: reserved for a future deer-inspired Mosky.
- **Kikiri**: reserved for a future rooster-inspired Mosky.

Bunbi and Kikiri are naming reservations, not newly implemented species. Preserve existing save keys, stable species IDs, asset paths and Android application ID. The existing internal project/app title remains unchanged pending a separate branding decision. Narration and audio are outside this naming pass.
